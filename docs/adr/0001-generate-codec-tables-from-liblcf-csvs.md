# Generate codec tables from liblcf's CSVs instead of hand-porting

liblcf defines the entire LCF format – 65 structs, 1043 fields with chunk IDs, types, defaults, persist flags, and 2k/2k3 markers – as language-neutral CSVs in `generator/csv/`, from which its C++ is generated. We vendor those CSVs (`vendor/liblcf-csv/`, from EasyRPG/liblcf @ `666e6c0`, MIT) and run our own dev-time TypeScript emitter over them; generated field descriptors and interfaces are committed, so consumers never run codegen. Hand-porting was rejected as error-prone busywork (every chunk ID and default must match exactly), and WASM-wrapping liblcf was rejected because it contradicts the pure-TypeScript, isomorphic goal. Staying on the upstream CSVs keeps us mergeable with liblcf's own format fixes.

The `*_easyrpg.csv` extension tables (EasyRPG Player / ManiacPatch chunks) are vendored alongside the base CSVs and merged by appending their rows after each struct's canonical rows – liblcf's own generator semantics, which is also its wire emission order. Only `functions.csv` (C++ helper method declarations) is excluded; it describes no wire data.
