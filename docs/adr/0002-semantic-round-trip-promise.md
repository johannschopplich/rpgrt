# Promise semantic round-trip, treat byte-identity as an internal test target

The public guarantee is semantic: decode → encode preserves meaning, and unedited records re-serialize to what a canonical writer produces. We do not promise byte-identical output for arbitrary input files, because the format itself makes that treacherous: LCF writers omit fields equal to their default (348 of 1043 fields carry a persist-if-default flag), and upstream liblcf drops unknown chunks, ships zero binary fixtures, and has never validated byte-identical round-trip – there is no oracle to be faithful to.

Byte-identity on real game files is instead an internal test goal, checked continuously against the local corpus (`test/corpus/`, real games, never committed) and reached by replicating the exact per-field `(default, persistIfDefault)` table and ascending-chunk-ID write order. Writes are always full canonical re-serialization (decode → mutate → encode); in-place splicing is impossible because BER length prefixes cascade. Divergences found in the corpus are triaged: either our writer is wrong (fix) or the source file contains data outside the vendored field tables (document, and decide whether unknown-chunk retention is worth its scope).
